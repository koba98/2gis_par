# 2GIS Full Catalog & Reviews Parser

Асинхронный парсер 2ГИС, который обходит **весь каталог региона** (все рубрики или заданные запросы), собирает полные карточки филиалов, контакты и **все отзывы**, и складывает всё в PostgreSQL в отдельную схему (по умолчанию `twogis`). Защита от блокировок (ротация прокси и User-Agent, бэкофф) сохранена.

## Как устроен полный обход

1. Регион ищется по названию (`region/search`), из его границ берётся bbox.
2. Загружается рубрикатор региона (`catalog/rubric/list`, рекурсивно). Для каждой конечной рубрики в очередь `crawl_tasks` кладётся тайл размером с регион.
3. Воркер ищет филиалы внутри полигона тайла (`3.0/items`, `type=branch`). API позволяет пролистать не больше `page_size × max_pages` результатов — если найдено больше, тайл делится на 4 части и так далее до `--min-tile`.
4. После каталога для каждого филиала выгружаются все отзывы по `next_link`. Повторный запуск дособирает только новые отзывы.

Очередь хранится в БД: прерванный обход (Ctrl+C, падение сети) продолжается с места остановки.

## Файлы

- **`parser.py`**: `TwoGisCrawler`, обход региона, рубрик, тайлов и отзывов, парсинг ответов API.
- **`storage.py`**: работа с PostgreSQL (psycopg 3, async): UPSERT данных и очередь тайлов.
- **`sql/schema.sql`**: DDL таблиц, индексов и представления `v_branches`.
- **`client.py`**: `AntiBanHttpClient`: прокси, User-Agent, общий для всех воркеров троттлинг, бэкофф при 429/403.
- **`main.py`**: CLI.

## Таблицы (схема `twogis`)

| Таблица | Что хранит |
|---|---|
| `regions` | регионы/города и их bbox |
| `rubrics` | рубрикатор: группы и конечные рубрики |
| `organizations` | организации (сети), объединяющие филиалы |
| `branches` | филиалы: название, юр. имя, адрес, этаж, район, координаты, рейтинг, график, атрибуты, полный `raw` JSON |
| `branch_rubrics` | связь филиал ↔ рубрика (с признаком основной) |
| `contacts` | телефоны, сайты, email, соцсети и мессенджеры |
| `reviews` | отзывы: рейтинг, текст, автор, лайки, фото, официальный ответ, полный `raw` JSON |
| `crawl_tasks` | очередь тайлов обхода и их статус |
| `v_branches` (view) | плоская выгрузка: филиал + рубрики + телефоны/сайты/email + число собранных отзывов |

В колонке `raw` (jsonb) хранится исходный ответ API, так что поля без отдельной колонки тоже не теряются.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить PG_DSN и ключи 2ГИС
python main.py init-db
```

Ключи API берутся на https://dev.2gis.com. Демо-ключ ограничен: страница до 10 элементов и не больше 5 страниц на запрос (это значения по умолчанию `--page-size 10 --max-pages 5`). С коммерческим ключом можно поставить `--page-size 50`.

## Использование

```bash
# Весь регион: все рубрики, все филиалы, все отзывы
python main.py crawl --region "Алматы"

# Только некоторые рубрики (по подстроке названия)
python main.py crawl --region "Алматы" --rubric "Кафе" --rubric "Ресторан"

# По поисковым запросам вместо рубрикатора, в заданной области
python main.py crawl --region "Москва" -q "аптека" -q "клиника" --bbox 37.35,55.55,37.85,55.95

# Без отзывов; отзывы потом отдельно (только ещё не собранные)
python main.py crawl --region "Алматы" --no-reviews
python main.py reviews --only-missing

# Начать обход региона заново
python main.py crawl --region "Алматы" --fresh

python main.py stats
```

## Параметры

Общие для всех команд:

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `--dsn` | строка подключения PostgreSQL | env `PG_DSN` |
| `--schema` | схема для таблиц | env `PG_SCHEMA` или `twogis` |
| `--catalog-key` / `--reviews-key` | ключи API 2ГИС | env `TWOGIS_CATALOG_KEY` / `TWOGIS_REVIEWS_KEY` |
| `--workers` | параллельные воркеры | `2` |
| `--delay` | базовая пауза между запросами (общая на всех воркеров), сек | `1.0` |
| `--max-delay` | максимальный бэкофф при 429/403, сек | `30.0` |
| `--timeout` | таймаут HTTP-запроса, сек | `15.0` |
| `--proxies` | файл со списком прокси (см. `proxies.example.txt`) | нет |
| `-v` | DEBUG-логи | выкл. |

`crawl`: `--region` или `--region-id` (обязательно), `--bbox`, `-q/--query`, `--rubric`, `--page-size`, `--max-pages`, `--min-tile`, `--no-reviews`, `--fresh`.

`reviews`: `--region-id`, `--only-missing`.
