# 2GIS Autonomous Catalog & Reviews Parser

Автономный асинхронный парсер каталога и отзывов 2ГИС с поддержкой ротации прокси, защитой от блокировок (Anti-Ban) и локальным хранилищем SQLite.

## Архитектура проекта

- **`database.py`** — модуль асинхронной работы с базой данных SQLite на базе `aiosqlite`.
  - Таблица `places`: id, название, юридическое наименование, категории, координаты (`latitude`, `longitude`), адрес, этаж, телефоны, сайты, соцсети, график работы, рейтинг, сводка отзывов.
  - Таблица `comments`: id, place_id (внешний ключ с каскадным удалением), автор, рейтинг, текст, дата, лайки.
  - Индексы по координатам (`idx_places_coords`), филиалу (`idx_comments_place_id`) и дате (`idx_comments_date`).
  - Режим WAL (`Write-Ahead Logging`) и проверка целостности внешних ключей.
- **`client.py`** — сетевой клиент `AntiBanHttpClient` с защитой от блокировок:
  - Пул актуальных браузерных `User-Agent`.
  - Менеджер прокси (`ProxyManager`) с ротацией и исключением нерабочих серверов.
  - Умный троттлинг запросов с джиттером.
  - Экспоненциальный бэкофф (динамическое увеличение пауз при получении кодов `429 Too Many Requests` и `403 Forbidden`).
- **`parser.py`** — модуль парсинга каталога 2ГИС (`TwoGisParser`):
  - Постраничный поиск организаций по запросу и координатам.
  - Извлечение полных реквизитов, гео-координат и контактов.
  - Полноценная пагинация отзывов по `next_link` / `offset_date`.
- **`main.py`** — CLI интерфейс запуска и координации.
- **`push_to_github.py`** — скрипт автоматической инициализации Git, привязки к `https://github.com/koba98/2gis_par`, создания коммита и отправки изменений.

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/koba98/2gis_par.git
cd 2gis_par
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

---

## Использование

### 1. Быстрый старт
Сбор 10 кафе в центре Москвы (по умолчанию):
```bash
python main.py -q "кафе" -n 10
```

### 2. Сбор с указанием координат и лимита отзывов
```bash
python main.py -q "ресторан" -l "37.6176,55.7558" -n 25 --max-reviews 50 --db restaurants.db
```

### 3. Сбор только организаций (без отзывов)
```bash
python main.py -q "аптека" -n 50 --no-reviews
```

### 4. Использование прокси
Создайте файл `proxies.txt` (см. `proxies.example.txt`):
```text
http://user:password@ip1:port
http://ip2:port
```
И запустите:
```bash
python main.py -q "отель" --proxies proxies.txt --delay 1.5
```

## Параметры командной строки

| Аргумент | Описание | Значение по умолчанию |
|---|---|---|
| `-q`, `--query` | Поисковый запрос | `"кафе"` |
| `-l`, `--location` | Координаты центра (долгота, широта: `lon,lat`) | `"37.6176,55.7558"` |
| `--city-id` | ID города в 2ГИС (опционально) | `None` |
| `-n`, `--limit` | Максимальное количество организаций | `10` |
| `--page-size` | Количество элементов на странице (1-50) | `10` |
| `--max-reviews` | Максимум отзывов на одну организацию | `20` |
| `--no-reviews` | Отключить сбор отзывов | `False` |
| `--proxies` | Файл со списком прокси | `None` |
| `--db` | Имя SQLite файла базы данных | `"2gis_data.db"` |
| `--delay` | Базовая задержка троттлинга (сек) | `1.0` |
| `--max-delay` | Максимальный бэкофф при 429/403 (сек) | `30.0` |
| `--timeout` | HTTP таймаут (сек) | `15.0` |
| `-v`, `--verbose` | Включить DEBUG логирование | `False` |
